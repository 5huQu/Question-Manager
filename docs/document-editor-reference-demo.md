# 文档编辑器参考图 Demo

开发环境路径：`/teaching-documents/demo/reference`。

该页面用于快速验证参考图的三栏编辑布局、顶部操作区、格式工具栏、卡片选中态和右侧属性面板。它只使用浏览器内 React state，不请求或写入真实数据，因此不会影响现有讲义、题库或文档编辑器。

## 正式编辑器已接入

- 正式路径 `/teaching-documents/:documentId` 已将页面外观替换为参考图的编辑器架构：固定标题栏、独立格式栏、可收折的大纲轨道、浅灰工作区中的白色纸张、300px 右侧属性检查器和底部状态栏。窄屏收起停靠面板，仍可按现有入口打开覆盖面板。
- 顶部统一格式栏直接作用于当前 Tiptap 文本块：字体、文字颜色、字号、常用文字标记、对齐、列表、缩进和行内公式。
- 内置卡片模板支持受控单卡覆盖：底色、边框颜色与宽度、圆角、四边内距；数据保存在既有文档 JSON 内，并经过前后端白名单校验。
- 自动保存、撤销/重做、真实块编辑、页面编辑与 A4 预览、章节大纲、自动编号、题库题目引用、素材上传与 TikZ 渲染均复用既有正式实现。

## 本期未提供

- 自定义卡片模板的创建、编辑、删除和跨文档共享；本期仅提供内置模板与单卡受控覆盖。
- 任意 CSS、任意色值或任意字号。为保证导出、分页和安全性，目前仅允许受控预设值。
- 多人协作、实时同步、协作者状态和冲突合并。现有能力为本地自动保存与版本冲突提示。
- 移动端三栏停靠布局。小屏设备保留编辑内容和现有覆盖面板入口，但不会同时展示两侧停靠栏。

未新增 API 路径、数据库表或迁移；新增字段均为既有 TeachingDocument JSON 中的可选字段。
